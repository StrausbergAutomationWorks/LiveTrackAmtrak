# Live Track Amtrak

A Home Assistant integration that puts live **Amtrak** train positions on your map.

> ### Status: in design. Not built yet.
> There is no releasable code in this repository. It is public so the design
> record and attribution are visible from the start.

Covers the Amtrak national network. Sibling integrations cover [VIA Rail](https://github.com/StrausbergAutomationWorks/LiveTrackViaRail) and [Brightline](https://github.com/StrausbergAutomationWorks/LiveTrackBrightline) from the same upstream feed.

If you install more than one of the three, they share a single upstream request
rather than making one each.
